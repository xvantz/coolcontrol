# coolcontrol 🧊

A lightweight fan control daemon for HP Victus laptops (EC registers `0x2C`/`0x2D`). Written in Zig 0.16 for maximum efficiency and safety.

## Features

- **Smart Auto Mode:** Fully customizable fan curve with linear interpolation.
- **Smoothing layer:** Kills fan howl on short CPU spikes. Exponential moving average (EMA) on temperature, downward-only hysteresis, and asymmetric slew-rate limiting on top of the curve.
- **Manual Control:** Set individual speeds for each fan (e.g., `set 40 60`).
- **Safety First:** Critical temperature bypass forces max fans immediately (default 92°C).
- **NixOS Ready:** Flake with a NixOS module for declarative configuration (nixpkgs 26.05, Zig 0.16).
- **Zero Dependencies:** Compiles to a tiny static binary.

## How smoothing works

Every second the daemon runs this pipeline:

```
raw temp -> EMA -> fan curve -> hysteresis -> slew limiter -> EC
```

| Parameter | Default | Meaning |
|---|---|---|
| `ema_alpha` | 0.3 | Temperature smoothing. Lower = calmer, slower reaction. |
| `max_step_up` | 6 | Fastest fan ramp-up, PWM units per second. |
| `max_step_down` | 8 | Fastest fan ramp-down, PWM units per second. |
| `min_step` | 2 | Deadband. Smaller changes are ignored, EC is left alone. |
| `hysteresis_temp` | 1.5 | Fans slow down only after temp dropped this much since the last change. |
| `hysteresis_delay_s` | 3 | Fans slow down only after this many seconds since the last change. |
| `only_downward` | true | Hysteresis applies to slowdowns only. Ramp-up is always immediate (within the slew limit). |
| `critical_temp` | 92.0 | Above this, everything is bypassed and fans go to max instantly. |

Rises are fast on purpose (overheating must not wait), falls are slow on purpose (silence). Both directions are capped so a 2-second spike never becomes a howl.

The monitor log shows both values for tuning:

```
[Monitor] Temp: 69.0C EMA: 61.1C target: 95 applied: 76 Mode: auto Fans: #0: 76 #1: 76
```

## Installation

### 1. Manual build (generic Linux)

Requirements: [Zig 0.16.0](https://ziglang.org/download/)

```bash
git clone https://github.com/xvantz/coolcontrol.git
cd coolcontrol
zig build -Doptimize=ReleaseSafe
# Binary lands at zig-out/bin/coolcontrol
sudo cp zig-out/bin/coolcontrol /usr/local/bin/
```

### 2. NixOS (flake)

```nix
{
  inputs.coolcontrol.url = "github:xvantz/coolcontrol";

  outputs = { self, nixpkgs, coolcontrol, ... }: {
    nixosConfigurations.your-hostname = nixpkgs.lib.nixosSystem {
      modules = [
        ./configuration.nix
        coolcontrol.nixosModules.default
      ];
    };
  };
}
```

```nix
services.coolcontrol = {
  enable = true;
  config = {
    critical_temp = 92.0;
    fan_curve = [
      { temp = 45.0; speed = 50; }
      { temp = 60.0; speed = 90; }
      { temp = 75.0; speed = 160; }
      { temp = 85.0; speed = 210; }
      { temp = 92.0; speed = 254; }
    ];
    smoothing = {
      ema_alpha = 0.3;
      max_step_up = 6;
      max_step_down = 8;
      min_step = 2;
      hysteresis_temp = 1.5;
      hysteresis_delay_s = 3;
      only_downward = true;
    };
  };
};
```

Anything missing from `config` falls back to the compiled defaults shown above.

## Configuration

`/etc/coolcontrol.json` (generated by the NixOS module, or handmade):

```json
{
    "ec_path": "/sys/kernel/debug/ec/ec0/io",
    "temp_path": "/sys/class/thermal/thermal_zone0/temp",
    "fan_addresses": [44, 45],
    "critical_temp": 92.0,
    "fan_curve": [
        {"temp": 45.0, "speed": 50},
        {"temp": 60.0, "speed": 90},
        {"temp": 75.0, "speed": 160},
        {"temp": 85.0, "speed": 210},
        {"temp": 92.0, "speed": 254}
    ],
    "smoothing": {
        "ema_alpha": 0.3,
        "max_step_up": 6,
        "max_step_down": 8,
        "min_step": 2,
        "hysteresis_temp": 1.5,
        "hysteresis_delay_s": 3,
        "only_downward": true
    }
}
```

A working sample lives in the repo as `coolcontrol.json`.

## Usage

```bash
# Start the daemon (usually handled by systemd)
sudo coolcontrol daemon --config /etc/coolcontrol.json

# Check current status
coolcontrol status

# Manual override
coolcontrol set 50      # Set all fans to 50/255
coolcontrol set 40 60   # Set Fan #0 to 40 and Fan #1 to 60

# Return to auto mode
coolcontrol auto
```

Stopping the daemon restores EC firmware control automatically.

## Requirements

The `ec_sys` module must be loaded with write support:

```bash
sudo modprobe ec_sys write_support=1
```

*The NixOS module handles this automatically.*
